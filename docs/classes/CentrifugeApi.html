centrifugeChannelTokenV1Raw

  • centrifugeChannelTokenV1Raw(requestParameters, initOverrides?): Promise<ApiResponse<AuthCentrifugoChannelResponse>>

  • Get a secret subscription token for an allowed channel_name in project_id. expires_in is the lifetime in seconds (currently 30 minutes); channel is the subscription name. Obtain a connection token separately from /method/centrifuge/auth/connect. Supported channels and access are checked; this is neither the OpenAPI tool catalog nor widget custom actions. channel_name is the requested channel name. Examples: $broadcast:123 — broadcast; $widget_template:507f1f77bcf86cd799439011 — integration template widget data. Get token for connect to centrifuge for channel

centrifugeConnectionTokenV1Raw

  • centrifugeConnectionTokenV1Raw(requestParameters, initOverrides?): Promise<ApiResponse<AuthCentrifugoConnectResponse>>

  • Get the secret Centrifugo connection token for the selected project_id, with expires_in in seconds (currently 5 minutes).
